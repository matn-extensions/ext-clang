# C/C++ Language Server (clangd)

Real-time C and C++ diagnostics, completion, hover, and indexing via clangd

## Details
- **Identifier**: `matn.ext.clang`
- **Version**: `1.0.0`
- **Category**: `languages`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **C/C++ Language Server (clangd)**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-clang
```
